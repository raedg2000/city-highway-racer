# Background music

The game looks for this file at runtime:

```text
assets/music/background.mp3
```

Recommended energetic Pixabay track:

- **The Race Is On - racing soundtrack videogame instrumental** by **melodyayresgriffiths**
- Pixabay page: https://pixabay.com/music/video-games-the-race-is-on-racing-soundtrack-videogame-instrumental-378331/

Backup option if you prefer an 80s/synthwave racing feel:

- **Asphalt Superstar - racing outrun synthwave retro video game** by **melodyayresgriffiths**
- Pixabay page: https://pixabay.com/music/video-games-asphalt-superstar-racing-outrun-synthwave-retro-video-game-158965/

Download one MP3 from Pixabay, rename it to `background.mp3`, and place it in this folder. The game also includes a softer Web Audio fallback loop so it remains playable before the MP3 is added.
